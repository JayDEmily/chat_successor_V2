# Download package contents

This TAR contains the **two written Chat Succession vision statements** and a **selected, labelled conversation record** alongside the existing Chat Succession synthesis and evidence files.

Start here:

1. `docs/TECHNOLOGY_AND_ORIGINAL_EXPERIMENT.md` — latest full vision statement, named technologies and what the original three-chat test actually achieved.
2. `docs/PREVIOUS_AGGREGATED_STATEMENT.md` — preceding aggregation of the user's ideas.
3. `docs/CONVERSATION_RECORD.md` — selected user statements from the conversation (not a complete ChatGPT export).
4. `docs/ORIGINAL_VISION.md` — separate earlier source-backed synthesis.
5. `evidence/VERIFIED_FINDINGS.md` and `evidence/UNKNOWN_AND_NOT_FOUND.md` — known evidence and unknowns.

Historical GitHub source branches are referenced in `docs/SOURCE_INVENTORY.md` but **are not included as complete branch checkouts in this particular sandbox archive**. The archive's purpose is the conversation/vision handover; it does not claim to contain an authenticated GitHub clone.
