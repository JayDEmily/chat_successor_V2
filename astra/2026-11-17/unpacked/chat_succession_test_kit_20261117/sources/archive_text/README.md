# Chat Succession — original vision and evidence archive

**Purpose:** Preserve the owner's original operating objective, the observed 17 November 2026 experiment, material found/not-found evidence, and recoverable code sources for a simpler successor-chat design.

**This is a local sandbox Git archive, not a deployed service.** Nothing here authorises another ChatGPT Send, changes the GitHub repository, or claims that an indefinite handover chain already works.

**Start with:**

1. [`docs/ORIGINAL_VISION.md`](docs/ORIGINAL_VISION.md) — user-defined objective and non-negotiables.
2. [`docs/LIGHTWEIGHT_PROTOCOL.md`](docs/LIGHTWEIGHT_PROTOCOL.md) — minimalist control flow, terminal states, short GitHub pointer.
3. [`evidence/VERIFIED_FINDINGS.md`](evidence/VERIFIED_FINDINGS.md) — observed outcomes and provenance.
4. [`evidence/UNKNOWN_AND_NOT_FOUND.md`](evidence/UNKNOWN_AND_NOT_FOUND.md) — limitations, failed checks, unknowns.
5. [`docs/SOURCE_INVENTORY.md`](docs/SOURCE_INVENTORY.md) — remote refs, source collection boundary, exact commitments and where historical code is represented.

The historical three-chat demonstration is **not** the product architecture: its strict packet validation, hash/commit pinning and one-shot journal do not become general requirements. The user's intended system supports a configurable upper bound such as **30 unique chats**, in one nominated ChatGPT Project, with same-chat continuation on `NEED_MORE_TIME` and user intervention on `ERROR`.

**Archive boundary:** Chat Succession project only. NVIDIA, Second Chat OCR and other repositories are not incorporated into this repo. OpenAI login/session secrets and the private local SQLite journal database are not included.
