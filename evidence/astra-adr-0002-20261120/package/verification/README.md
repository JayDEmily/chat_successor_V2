No fake live observations or resource samples have been inserted into the
acceptance templates. JSON null / CSV blank means unobserved, not zero.

Git's `fsck` and supplied-ref matches do not independently prove remote
advertisement at capture or today. File hashes do not certify authorship.
Matching source code does not prove which backend an installed wrapper uses.

The reproducer refuses an existing output directory, verifies the exact input
archive hash, extracts only into a new temporary directory, restricts Git to
file transport, and destroys each newly created mirror before opening the next.
Only the accompanying reviewed offline suites and validators are executed.

For a new run, use a new output directory. Do not replace these captured results
with new ones without retaining the candidate/host/version distinction.
