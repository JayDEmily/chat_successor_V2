Initial proposal: reuse Windows UI Automation for a bounded successor launch; give each new chat an exact GitHub assignment. Compare worker-launched succession with a small GitHub watcher before choosing ongoing orchestration. The first joined experiment is three fresh chats with a fixed stop after the third.

Returning to the original chat, discovering the original iPhone conversation and forwarding answer bodies are outside this exploration's requirements. The Second Chat OCR project continues separately.

Repository creation and planning are authorised. This publication does not start browser automation, install anything or launch chats. Implementation and experiment decisions are explicit steps in the plan.
