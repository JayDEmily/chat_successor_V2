## Accepted scope

Keep the existing Windows/Chrome/Desktop Commander/Ubuntu Git controller. Implement leaves L01–L10 as ordered, with A2-G0–G6 acceptance and an evidence-backed install/release decision. Repair explicit account routing, safe durable pause/action identity, view recovery, scoped approval and run identity. Exercise existing disposable fixtures before adding new repositories. Use one existing GitHub working branch and keep `main` unchanged. Publish raw reproducible evidence and a clear distinction between verified, assisted, held and not-run results.

This is a standing implementation grant, including bounded fault injection and later controlled concurrent acceptance on verified disposable workloads. Normal successful independent review, acceptance, checkpoint publication and already scoped candidate installation may proceed without renewed approval.

## Preserved exclusions and stop conditions

Do **not** automatically release the separately paused Rowing or SolidWorks runs. The programme authority is not a direction to resume those specific previously paused actions or change their work. Do not touch unrelated active workers, browser drafts, private account data, unrelated repository branches, or merge to `main`. A missing, mismatched or possibly submitted browser action remains a safety hold until positively reconciled, not permission to retry. Installed account/profile identity, iPhone interaction and live acceptance must be established on the actual target account; do not claim old tests as new evidence.

The owner's general permission to create a repository is conditional on it being needed for the approved plan and independently verified creator access; it is not a requirement to proliferate repositories. Existing Cat/Dog, Bird/Pig and approval fixtures are preferred.

## Release decision

Complete recorded A2-G0–G5 predicates and independent closeout before declaring full release. Publish the current evidence and identify any user-only account action if a genuine technical blocker is reached. Do not turn this standing grant into authorisation to override a failed gate, clear an unrelated pause or make a materially new architecture.
