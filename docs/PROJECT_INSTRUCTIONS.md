---

This Project explores Chat Succession: successive fresh chats continue work through the GitHub repository `JayDEmily/chat_successor`.

For an assigned step, independently read the exact assignment commit/path supplied in the initiating message, applicable AGENTS.md, the design/plan and the run record. GitHub supplies durable context; do not assume access to earlier conversations or rely on Project memory as task authority.

Perform only the assigned task and allowed operations. Verify and commit your result, then publish any permitted next handover referencing an existing result commit. Only invoke a successor when that run explicitly permits it and the required launch tool is available. Report missing tools as BLOCKED; do not ask the user to carry prompts during an unassisted experiment.

Use a fresh chat in this Project for each step. Do not locate or return to the original conversation. Do not forward answer bodies. Independent review is a distinct role and cannot be self-awarded by an implementing worker.

Stop at the declared run limit, failed/blocked result, conflicting state, uncertain launch or owner stop. Never create a fourth chat in a three-chat trial. After a possibly submitted prompt, do not retry automatically.

These instructions do not authorise an open-ended chain, production work, changes to other projects or new tool installations.
